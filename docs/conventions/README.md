# Content conventions

Shared rules for every OzarLand community repository. They exist to make content findable, comparable and safe,
and they are kept as short as possible.

| Convention | What it covers |
|---|---|
| [Content metadata](content-metadata.md) | How every page declares its OpenStack release, components, deployment method, status and confirmations |
| [Runbook structure](runbook-structure.md) | The sections every runbook has, and why |
| [Risk warnings](risk-warnings.md) | How to flag read-only, state-changing and destructive commands |
| [Sensitive data](sensitive-data.md) | What must never be published, and how to redact |
| [Licensing](licensing.md) | Apache License 2.0 for all content, documentation and code alike |
| [README identity](readme-identity.md) | The tagline, README layout, visual language and shared closing block of every repository |

Document templates implementing these conventions are under [`community/templates/`](../../community/templates/).
